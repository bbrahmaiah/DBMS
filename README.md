# BookMyShow DBMS Project

## Overview
This project implements a BookMyShow-style movie ticket booking database using SQL Server.

## Database Tables
1. Users
2. Movies
3. Theaters
4. Shows
5. Bookings
6. Payments

## Constraints Used
- PRIMARY KEY
- FOREIGN KEY
- NOT NULL
- UNIQUE
- CHECK
